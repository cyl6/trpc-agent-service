trpc-agent-service

多租户 IM Agent 平台 · 版本 __VERSION__（commit __COMMIT__）

服务端点

健康检查GET /healthz
就绪检查GET /readyz
Prometheus 指标GET /metrics
IM WebhookPOST /webhooks/{channel}/{binding}
本地对话验收POST /v1/chat/{tenant}（Admin Bearer Token）
租户列表GET /admin/v1/tenants
配置热更新POST /admin/v1/reload
租户回滚POST /admin/v1/tenants/{tenant}/rollback

公网消息只应进入 /webhooks/*；/v1/chat 与 /admin/* 受 ADMIN_TOKEN 保护，仅用于本地验收与运维。

运维提示

启动：./start.sh；停止：./stop.sh；构建：./build.sh；测试覆盖率：./coverage.sh。
运行日志与 PID 位于 data/，租户配置见 config/example.yaml，架构设计见 docs/。
